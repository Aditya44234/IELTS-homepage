# AceIt - IELTS Preparation Platform

AceIt is a modern, responsive React web application designed to help students master the IELTS exam through AI-powered practice tests, expert tutoring, and personalized study plans. The project uses Tailwind CSS for styling and features a sleek UI with real-time interactive components.

## About

AceIt aims to provide personalized, AI-driven IELTS study experiences. It includes features such as:

- Real-time score reporting and progress tracking
- Comprehensive study materials and practice modules
- Responsive UI optimized for mobile and desktop
- User-friendly navigation with dropdown menus
- Reusable React component architecture

---

## Features

- Sticky floating Navbar with dropdowns for easy navigation  
- Hero section with headline, sub-text, button, image/banner
- Feature cards grid showcasing platform benefits with adaptive layout  
- Testimonials section to highlight user success stories  
- Responsive design using Tailwind CSS and custom color theming

## Getting Started

### Prerequisites

- Node.js 16+  
- npm or yarn  

### Installation

1. Clone the repository:
git clone https://github.com/Aditya44234/IELTS-homepage.git
cd AceIt


2. Install dependencies:
npm install


3. Start the development server:
npm run dev




4. Open http://localhost:3000 to view in the browser.

---

## Available Scripts

- `npm run dev` — Start local development server  
- `npm run build` — Build for production  
- `npm run preview` — Preview production build locally  
- `npm run lint` — Run code linter
